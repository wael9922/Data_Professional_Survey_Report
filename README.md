# 📊 Data Professional Survey Breakdown

This project presents an interactive Power BI dashboard analyzing survey responses from **630 data professionals** around the world. The dashboard provides insights into salary trends, programming language preferences, demographic patterns, and job satisfaction levels.

---

## Insights

- Data Scientists have the highest average salary.

- Python is the favorite programming language among data professionals.

- The most important factor survey takers look for in a new job is salary, which is consistent with their relatively low satisfaction with current pay.

## 🚀 Getting Started

To explore the dashboard:
1. Download the `.pbix` file from this repo.
2. Open it with [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Interact with filters and visuals to explore the data.

## Conclusion:

Offering better salaries can increase data professionals’ satisfaction with their current jobs and reduce their likelihood of seeking new opportunities.
